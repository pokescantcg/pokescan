We introduced a regression after adding card variants and resync logic.

Current issues:
1. Some Pokémon sets no longer load all cards
2. Card details fail to open and show "Card unavailable"
3. Older sets are most affected
4. Variant support may be overwriting cards
5. Navigation to CardDetails is unreliable

Fix the entire card loading pipeline safely.

REQUIRED FIXES:

1. REMOVE ALL DEDUPE BY CARD NUMBER
Search entire project for:
- uniqBy(cards, "number")
- map[card.number]
- existing.number === card.number
- reduce() using card.number as key
- ON CONFLICT(number)

Replace ALL card uniqueness logic to use:
card.id

2. FIX PAGINATION
Any set sync/fetch logic must fetch ALL pages from the Pokémon API.

Use:
- pageSize=250
- loop until returned batch < 250

Correct pattern:

let page = 1;
let allCards = [];
let hasMore = true;

while (hasMore) {
  const response = await fetch(
    `${API_BASE_URL}/api/pokemon/cards?q=set.id:${setId}&page=${page}&pageSize=250`
  );

  const json = await response.json();
  const batch = json.data || [];

  allCards.push(...batch);

  hasMore = batch.length === 250;
  page++;
}

- use passed route.params.card first
